# 数据与来源说明

## 项目性质

个人项目：面向本地生活服务的售后客服 Agent。

问题定义（三方任务协同、异步不阻塞、焦点漂移）来自本地生活服务售后客服这一**公开可见的业务场景**——任何用过团购券并找过客服的人都能观察到这些难点。架构、代码、决策表、评测方法与全部指标为独立实现。

**不含**任何公司内部代码、内部文档原文、线上数据、真实用户会话、内部模型名称、服务地址与凭据。

## 仓库内的数据

全部为构造样例：

| 外呼与退款结果 | 确定性 mock（`AsyncBus(seed=N)`） |

## 指标口径

README 中的指标均为**离线可复现值**——克隆仓库后 `./scripts/ci.sh` 可复现全部六项。

缓存指标默认由脚本客户端模拟，用于配置间的相对比较；`--live` 走真实 API，从 `usage.cache_read_input_tokens` 读取真实值。

以下需要线上部署与真实流量才能度量，因此不在本仓库的指标范围内：query 级时延分布、用户满意度、与线上基线对比的工具调用准确率。
