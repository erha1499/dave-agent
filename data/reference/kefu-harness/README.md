# kefu-harness 参考语料

来源：[wanglongze123/kefu-harness](https://github.com/wanglongze123/kefu-harness/tree/305590129ea020a5a362e07b294fd1587b8f53fd)，固定 commit `305590129ea020a5a362e07b294fd1587b8f53fd`。原作者为 wanglongze123，版权与许可保留在 [LICENSE](LICENSE)，原始数据性质说明保留在 [NOTICE.md](NOTICE.md)。本目录的五份上游文件按原相对路径、原字节保存；`source.json` 记录 SHA256、字节数和选择清单。没有执行上游代码，也没有复制检索实现。

这是独立的离线检索参考语料，全部为上游构造样例，不是线上用户数据或真实店铺政策。它不写入当前 MySQL 知识库，不通过客服工具提供，也不映射到 `shop-demo-*`。本项目原有业务规则和资金授权边界不由这些文档改变。

## 全量与选集

| 范围 | 文档 | 常规问题 | hard 问题 |
| --- | ---: | ---: | ---: |
| 原始全量 | 35 | 136 | 76 |
| 餐饮、通用退款与核销选集 | 11 | 44 | 26 |

选集固定为 `CY001–CY003`、`RF001–RF005`、`VF001–VF002`、`MC002`。包含餐饮使用、退款、核销/误核销和闭店退款；MC002 使选集保留场景描述类问题。选集 hard 为 14 条口语省略、11 条同义替换、1 条场景描述。

loader 返回完整 35 篇文档、212 道题及 `selectedIds`，评测器自行选择子集或全量。子集问题仅在其全部 `relevant` 都属于选择清单时保留。题目 ID 按原文件行号生成，如 `standard-0001`、`hard-0001`；筛选后不重新编号。原始文档、问题、标签均未改写。

可运行本项目的离线命令：

```sh
node scripts/retrieval-check.ts
node scripts/retrieval-baseline.ts
```

这些命令不是上游 CI，也不证明客服回答质量、工具授权、模型效果或 QQ 送达。子集分数不能冒充 35 篇/212 题的全量成绩。

## 字段及覆盖边界

文档包含 `doc_id/title/text/industry/tags`，仅 SH001/SH002 含 `shop_id=shop_1001`；行业为通用 24、餐饮 5、丽人/休娱/酒旅各 2。没有文档有效期字段。常规问题包含 `query/relevant/industry/shop_id`，132 条 shop_id 为 null，4 条指向 shop_1001。

hard 包含 `query/relevant/kind/ctx`：口语省略 35、同义替换 32、场景描述 9。`ctx` 是构造的焦点订单背景：32 条为空，44 条有 industry 和 sku_name，其中 21 条含 verified（已核销 true 10 条、未核销 false 11 条）。verified 不表示身份认证或退款授权。保留 ctx 不意味着默认拼接它；应把原查询检索与上下文改写作为不同实验。

固定版本的上游评测在开启 rewrite 时传入 ctx：商品名仅用于指代补全，核销状态仅用于退改类查询；industry 不参与拼接。常规集的行业标签也没有由上游评测作为检索硬过滤传入。上游 `build_hard_evalset.py` 不输出当前 JSONL 的 ctx，还含两条会被剔除的 LR202 错误标签，因此不运行生成器重建这份固定归档。

当前归档无缺失必填字段、重复 doc_id、悬空 relevant、重复查询或同一输入的冲突标签；每题都只标一个相关文档。hard 不覆盖 SH001/SH002。数据缺少无答案、跨店负例、多证据和回答忠实度标注，不能用单标签检索成绩推断这些能力。loader 检查范围一致性：通用文档可适用于有行业/店铺上下文的问题；专属文档不能跨行业、跨店或在缺少店铺上下文时充当相关证据。

## 与本项目业务的差异

- RF001 描述未核销免商家同意及过期退；本项目模拟退款要求持久商家批准，过期券需另行核实，不能据此放开执行条件。
- RF005 描述真实支付到账周期和订单页面入口；本项目仅模拟资金操作，不应承诺这些渠道或入口。
- VF002、MC002 描述平台申诉、恢复券状态等能力；本项目未实现这些操作。
- SH001 是 2026 年 7–8 月活动，导入时已过期，但原数据没有 valid_until；SH001/SH002 店铺也不是本项目演示店，均未纳入选集。

如后续将参考文本改写为本项目运行时规则，应另存版本、注明修改与原文档 ID，并重新标注适用问题；本目录继续保留原文及原标签，避免混淆参考数据与本项目政策。
