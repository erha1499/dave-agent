# C1 可信上下文：实现与验收记录

本阶段解决客服续问中的订单、金额、对象和政策话题指代。身份来自可信 QQ 入口；范围和状态来自本轮重新授权的订单读取；历史模型回答不授予权限。复用 Pi 的动作选择循环，项目实现业务 Controller、受限的宿主上下文和知识服务。

截至本轮冻结验收，C1 **未达到准入指标**。可信金额引用、切单和知识服务已经接通，但新固定验证 accepted Recall@5 为 50%，并暴露金额指代漏识别、状态描述误澄清和知识缺失声明被误接收的问题。所有阶段的输入、实现和结果分开保留；没有切换 QQ 默认方案。

## 7. C1 准入合同（新固定验证执行前声明）

| 指标 | 定义 | 门槛 |
