# MiniMax Agent 面试映射与本轮补齐

本轮基于用户提供的面试逐字稿，核对语雀 23 篇现有课程及 dave-agent 实现。面试叙述只作为提问清单，不验证视频中的履历、薪酬或招聘政策，也不推断 MiniMax 的内部系统。

原课程已经详细覆盖身份、确认、异步任务、事务幂等、通知未知、持久查询、检索证据与有界实验。本轮开始时的主要缺口是把这些能力串成最终答复、工具、状态和成本的联合证明；正式请求预算、事务提交窗口的崩溃检查、长上下文保护；以及 Skill、异常选择、成本手算、模型路由边界和 owner 思考的教学。以下分别记录已经交付的证据和仍在进行的部分。

本轮代码范围为 M1–M4，草稿范围为 8 篇扩写、3 篇新课及导航。验收结果以 [plan](../plan.md) 和专项结果文档为准；候选 C1、完整 O4、O5 的既有未准入状态不被局部补齐覆盖。

## 为何不把所有名词都加进代码

通用 Planner、多 Agent、长期向量记忆、自动模型路由、AST 服务和完整监控平台，目前没有比稳定闭环更明确的业务收益。本轮通过课程给出适用条件、最小设计练习与停止依据，保留“未实现”的事实。面试应说明为什么选择现有实现，以及什么新失败会改变这个选择。

本地草稿入口见 [导入包](./yuque-drafts/minimax/README.md)。发布语雀、真实 QQ 重验、作者独立复现和真实商业运营不由本轮本地文档交付代替。
